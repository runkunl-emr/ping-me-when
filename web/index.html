Discord token

Your token never leaves this machine. It's stored in config.json next to the app.

How do I get my token?
  1. Open Discord in a browser (not the desktop app).
  2. Press Cmd+Option+I (Mac) or F12 (Win/Linux) to open DevTools.
  3. Click the Network tab.
  4. Click any channel in Discord — requests will appear.
  5. Click any request to discord.com/api/... → Headers → find Authorization:.
  6. Copy the long string after Authorization: and paste it above.

Treat your token like a password. Anyone with it can read every channel you can see.
